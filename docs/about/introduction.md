# 关于项目

## 项目背景

ViteDocs 诞生于一个常见的需求矛盾：

> "我想要一个漂亮的文档站点，文档内容公开协作，但我的设计系统不希望被任何人复制。"

传统的解决方案要么全开源（设计暴露），要么全私有（失去协作价值）。ViteDocs 通过**双仓架构**实现了两全其美。

## 设计理念

1. **扁平化**：去除多余的渐变、阴影和装饰，让内容本身成为焦点
2. **二次元**：粉色系配色 + 圆润边角 + 活泼字体，营造年轻友好的视觉氛围
3. **实用主义**：用最小复杂度解决核心问题——内容与样式分离

## 技术选型理由

- **VitePress**：Vite 驱动的静态站点生成器，构建速度快，生态成熟
- **React + Vue 混合**：利用 React Markdown 渲染内容，VitePress 提供框架支持
- **GitHub Pages**：免费托管，零运维成本
- **GitHub Actions**：强大的 CI/CD，无需额外服务
